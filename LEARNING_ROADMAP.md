## 🎓 Study Plan Recommendation

### Phase 1: Foundation (Weeks 1-4)
1. **Arrays and Strings** → Master two pointers and sliding window
2. **Linked List** → Practice fast-slow pointer patterns
3. **Stacks and Queues** → Understand monotonic patterns
4. **Hash Table** → Frequency and pattern problems

**Daily Goal**: 3-4 problems, 2 hours study time

---

### Phase 2: Core Algorithms (Weeks 5-10)
1. **Binary Search** → All variations
2. **Sorting** → Understand complexities
3. **Binary Trees** → Traversals and BST operations
4. **Dynamic Programming** → Start with 1D DP

**Daily Goal**: 4-5 problems, 3 hours study time

---

### Phase 3: Advanced Topics (Weeks 11-14)
1. **Graphs** → BFS, DFS, shortest paths
2. **Backtracking** → Pattern recognition
3. **Greedy** → Interval problems
4. **Heaps** → Top K patterns
5. **Bit Manipulation** → XOR tricks

**Daily Goal**: 5-6 problems, 3-4 hours study time

---

### Phase 4: Mock Interviews (Weeks 15-16)
- Practice 2-3 problems daily under timed conditions
- Focus on communication and explanation
- Review mistakes and optimize solutions
